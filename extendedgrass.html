Overview

This guide will not cover the basics of LOD generation, the settings and underlying LOD setup are based on the LOD Guide. Familiarize yourself with that before continuing.

Introduction

Grass Cache

Grass caching is the process of regenerating the files that tell the game where grass can be, solving most clipping issues. In the past, generating new grass cache often took hours, as we had to run the caching live in-game. This is no longer a problem thanks to Faster NGIO Grass Cache.

Extended Grass

No Grass In Objects allows loading the new cache mentioned before, and is also able to extend grass past the grid of fully loaded cells. Normally, this lowers performance down to a crawl, but Community Shaders' Grass Optimizations addon turns it around and makes it quite a cheap visual upgrade.

Extending grass with NGIO + Grass Optimizations is preferable to the legacy method of generating grass LOD in Object LOD with DynDOLOD, as that would use a different set of shaders and not perfectly match the look of loaded grass. The new method does not have this problem, while performing better.

Drag the slider handle to compare how the game looks with extended grass. Use the dropdown to select different comparison sets.

Process

Creating a Separator in MO2

  1. Right-click the empty space in the left pane of MO2 and select Create separator.
  2. Name the separator Extended Grass.

Installing Resources

On top of the resources from the LOD Guide, you should add these. You might already have Community Shaders, but the Grass Optimizations addon is now required:

  1. Community Shaders
    • Main Files - Community Shaders
    • Grass Optimizations - Community Shaders
      • Main Files - Grass Optimizations
  2. No Grass In Objects
    • Main Files - NGIO - NG (1.6.14)
    • Optional Files - Config INI - GrassControl.ini (1.6.3)
      1. Once the configuration file has been installed, double-click it in the left pane of MO2.
      2. In the INI Files tab, select SKSE/Plugins/GrassControl.ini
      3. Change only the following options:
        • Set Use-grass-cache to true.
        • Set Extend-grass-distance to true.
        • Set Overwrite-grass-distance to 40000.
        • Set Overwrite-grass-fade-range to 0.
        • Set Only-load-from-cache to true.
        • Set Load-from-BSA to true.
      4. Save your changes.
  3. Grass Cache Helper NG
    • Main Files - Grass Cache Helper NG

IMPORTANT:
Enable all resources in MO2 before continuing.

Grass Cache

If you use a DBFE modlist with no changes to the game world, you can skip manual grass cache generation (and packing) by using the DBF Grass Cache file here.

First, set up the empty mod that will store the grass cache:

  1. In MO2, click the tiny wrench icon at the top, next to the mod counter, then click Create empty mod.
  2. Title the mod Grass Cache
  3. Right-click on your Grass Cache mod and select Open in Explorer.
  4. From from newly opened window, copy the file path.

Then generate it (in that folder):
  1. Download the latest Faster NGIO Grass Cache.
  2. Once the download has finished, extract the contents of the archive to any location of your choice (do not use a UAC protected folder or the game folder).
  3. In MO2, select the button at the top of MO2 to open the executables menu.
  4. Click the + at the top of the window and the select Add from file...
  5. From the pop-up, navigate to where the tool is and select FasterNGIO.exe.
  6. Set the output folder to the one you copied earlier, then type \Grass at the end of the path.
  7. Click Generate.
  8. When complete, you will see a message saying "OK: Done in...", you can now close the program.

Packing Grass Cache

This step is not necessary, but will reduce loading time of grass caches by the game by packing them into optimized archive files (BSAs). This translates to less stuttering when entering new areas.

  1. Download Cathedral Assets Optimizer (you should already have this, as it's used in the LOD Guide).
  2. Once the download has finished, extract the contents of the archive.
  3. Run Cathedral_Assets_Optimizer.exe.
  4. Tick the Create BSA box.
  5. In Mod Organizer 2, right-click on your Grass Cache mod and select Open in Explorer.
  6. From from newly opened window, copy the file path, then paste it into CAO (right below the profile drop-down).
  7. Click the Run button.
  8. Once the process is complete, you will see a message saying "Done" at the bottom.
  9. Click F5 while you are on MO2 without any menu open, and make sure the new plugin (it loads the archive) is enabled in your load order.
